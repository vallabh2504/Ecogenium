Section 02 · Owner: Energy management

Strategy Simulation — Strategy Implementation

✅ Updates DONE

  • Full EMS suite A–G simulated over the 11-lap / 14.5 km race with a cross-strategy comparison table.
  • Strategy G chosen (LPF feedforward + SOC-PI) — adaptive, charge-sustaining, no pre-tuned profile.
  • Measured RPM×Torque BAFANG motor map folded in — lifted mileage ~165 → ~235 km/m³.
  • Pulse-and-glide profile picked by grid search (V_HI 10, V_LO 6 m/s, P_pulse 1400 W); robustness checked on WLTC + NEDC.

🔧 Work left for race OPEN

  • Translate Strategy G to Simulink: LPF→discrete TF, K_p gain, K_i PID + anti-windup, lap-offset triggered subsystem, floor+clip.
  • Model-in-loop validation against the live telematics signals (I_mot, U_mot, U_soc).
  • Re-tune K_p / K_i against the real SC + FC behaviour; confirm charge-neutral on measured SOC.
  • Driver speed targets / pulse-and-glide coaching cues.
  • Fallback rule-based FSM if the adaptive loop misbehaves.

🧪 6/6 testing plan PLAN

  • Replay recorded telematics drive data through the Strategy-G sim; confirm km/m³ & ΔSOC.
  • Closed-loop sim with SC + FC models for 11 laps — check FC floor ≥ 100 W, no integrator windup.
  • Sensitivity sweep on K_p around 2075 W/SOC; verify the charge-sustaining band.
  • Regression: Simulink port output must match the Python reference.
Exit criterion: Simulink Strategy G matches Python to ±1% on H₂ & ends charge-neutral.
